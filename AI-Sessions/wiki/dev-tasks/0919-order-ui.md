# 09-19 (토) — 발주 입력 화면

## Summary

발주를 입력하는 화면을 만든다. 아직 변환은 붙이지 않는다.
완료 기준: 텍스트·음성으로 입력할 수 있고, 모바일에서 한 손으로 쓸 만하다.

## Details

설계는 [[order-design]].

### 작업

1. 발주 입력 화면 — 큰 텍스트 영역 + 음성 버튼
2. 확인 화면의 뼈대 (변환 결과가 들어갈 자리)
3. 음성 입력 — Web Speech API

### 주의

- **모바일 우선.** 사장님은 주방에서 한 손으로 쓴다. 버튼은 크게, 입력은 한 화면에
- 음성은 Web Speech API로 공짜지만 **주방 소음에서 정확도가 떨어진다.**
  텍스트 입력을 항상 병행한다. 음성은 편의 기능이지 대체재가 아니다
- 브라우저 미지원 시 음성 버튼을 숨긴다(에러를 띄우지 않는다)

## 완료 확인

1. 모바일 폭에서 입력 → 확인 화면 이동
2. 음성 버튼 → 받아쓴 텍스트가 입력창에 들어감
3. 음성 미지원 브라우저에서 버튼이 안 보임
