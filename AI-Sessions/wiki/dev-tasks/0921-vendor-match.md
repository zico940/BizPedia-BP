# 09-21 (월) — 거래처명 매칭

## Summary

변환 결과의 거래처 힌트("김사장")를 실제 거래처와 연결한다.
완료 기준: 동명이인이 있으면 되묻고, 없으면 등록을 유도한다.

## Details

설계는 [[order-design#2. 거래처명 매칭 — 실제 난관]].

### 판정 순서

| 순서 | 조건 | 처리 |
|---|---|---|
| 1 | 정확히 일치 | 확정 |
| 2 | 경칭·공백 제거 후 일치 | 확정 |
| 3 | 부분 일치 **1건** | 확정 + 화면에 근거 표시 |
| 4 | 부분 일치 **2건 이상** | **되묻기** — 후보 버튼 |
| 5 | 없음 | **되묻기** — 거래처 등록 유도 |

### 주의

**추측해서 확정하지 않는다.** 잘못된 거래처로 발주가 나가면 실물 손해다.
4·5번은 실패가 아니라 정상 흐름이므로 화면을 제대로 만든다.

경칭 목록은 최소로 시작한다 — `님`, `사장님`, `사장`. 늘리는 건 나중에.

```
# ponytail: 문자열 정규화 + 부분 일치. 퍼지 매칭 라이브러리는 오탐이 늘면 그때.
```

## 완료 확인

`assert` 기반 점검:

- "김사장님" → "김사장" 확정
- 동명이인 2건 → 되묻기
- 없는 이름 → 등록 유도
