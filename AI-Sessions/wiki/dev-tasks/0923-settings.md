# 09-23 (수) — 설정 · 개인정보처리방침

## Summary

AI 검색 범위를 설정하고, 개인정보처리방침 페이지를 완성한다.
완료 기준: `ai_range_days`가 저장되고, 클라이언트 조작으로 무시할 수 없다.

추석(09-24~27) 직전 날이다. 연휴 전에 매듭짓는다.

## Details

### 작업

1. 설정 화면 — `ai_range_days` 변경 (1~365)
2. 개인정보처리방침 페이지 (09-17에 못 했으면 여기서 반드시)

### 설정은 보안 경계다

`ai_range_days`는 성능 설정이 아니다. **범위 밖 데이터가 조회되면 안 된다**는 요구다.

- 값은 `app_users` 테이블에 저장
- 조회 시 **세션 유저의 값을 서버에서 읽어** 쿼리에 넣는다
- **클라이언트가 보낸 범위값을 절대 신뢰하지 않는다**

자세한 것은 [[data-isolation-policy#규칙 3 — 날짜 범위는 성능 설정이 아니라 보안 경계]].

### 개인정보처리방침

이름·전화번호를 받는 순간 **법적 의무**다. 정적 페이지 한 장이면 된다.
가입 화면의 동의 체크박스에서 링크한다.

수집 항목: 카카오 식별자, 닉네임, 프로필 이미지, 이름, 전화번호, 이메일(선택),
매장명, 업종, 거래처 정보, 발주 내역.

## 완료 확인

1. `ai_range_days`를 1로 저장 → `app_users` 행에 반영
2. 요청 본문에 다른 범위값을 넣어도 **무시되는지** 확인
3. 가입 화면에서 처리방침 링크가 열리는지
