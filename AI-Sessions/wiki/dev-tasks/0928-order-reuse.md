# 09-28 (월) — 발주 재사용

## Summary

"어제처럼 발주해줘"를 구현한다.
완료 기준: 과거 발주를 불러와 확인 후 재발주할 수 있고, 설정 범위 밖은 조회되지 않는다.

추석(09-24~27) 직후 첫 날이다.

## Details

설계는 [[order-design#3. 발주 재사용 — "어제처럼"]].

### 흐름

```
"어제처럼 발주해줘"
  ├ 정규식 파싱 (오늘/어제/그저께/N일 전/이번 주/지난주)
  │    └ 성공 → LLM 건너뛰고 바로 SQL (0.3초)
  └ 실패 → LLM에게 날짜 추출
       ↓
  SQL 조회 — user_id + ai_range_days 범위 안에서만
       ↓
  확인 리스트 → 승인 → **새 orders 행**으로 저장
```

### 주의

- **정규식이 먼저, LLM은 폴백.** 표현이 뻔해서 대부분 정규식에서 잡히고,
  잡히면 0.3초에 끝난다
- **과거 발주를 수정하지 않는다.** 재사용은 항상 새 행을 만든다.
  원본이 바뀌면 "어제 뭘 시켰더라"의 답이 사라진다
- 두 경계가 동시에 걸린다 — `user_id`(개인정보)와 `ai_range_days`(설정 범위).
  후자는 **세션에서 읽는다.** 클라이언트 값을 쓰지 않는다
- 승인 전에는 저장하지 않는다

## 완료 확인

`assert` 기반 점검:

- "어제"·"3일 전"·"지난주" → 올바른 날짜
- `ai_range_days=1`에서 10일 전 발주가 **안 나오는지**

육안 확인:

1. "어제처럼 발주해줘" → 리스트 표시 → **승인 전에는 저장되지 않음**
2. 승인 후 이력에 새 행이 생기고 **원본은 그대로**
