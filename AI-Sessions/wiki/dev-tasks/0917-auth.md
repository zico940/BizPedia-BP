# 09-17 (목) — 카카오 로그인 · 가입

## Summary

카카오 로그인과 가입 폼을 만든다.
완료 기준: 로그인 → 가입 → 홈 왕복이 되고, 재로그인 시 가입 폼이 다시 뜨지 않는다.

## Details

설계는 [[auth-design]].

### 작업

1. `auth.ts` + `app/api/auth/[...nextauth]/route.ts`
2. `lib/db/queries.ts` 첫 함수 — `getUserByKakaoId`, `createUser`
3. 가입 폼 1화면 (이름·전화·매장명·업종 + 동의 체크박스)
4. 개인정보처리방침 정적 페이지

### 주의

- 식별 기준은 `kakao_id`. 이메일이 아니다(선택 동의라 비어 올 수 있다)
- 전화번호는 하이픈 제거 후 저장
- 우리 테이블은 `app_users`다. Auth.js의 `users`와 별개로 공존한다
- 카카오 콘솔 Redirect URI에 **로컬 URL도** 등록. 빠뜨리면 개발 내내 막힌다
- `lib/db/queries.ts`를 거치지 않는 쿼리를 만들지 않는다([[data-isolation-policy]])

### 업종 선택지

"아직 준비 중(창업 예정)"을 넣어 `status='preparing'`을 받아둔다.
**분기 화면은 10월**이지만([[user-mode-design]]), 값은 지금부터 쌓는다.
나중에 마이그레이션을 다시 쓰지 않기 위해서다.

## 완료 확인

1. 카카오 로그인 → 가입 폼 → `app_users` 행 생성 (Auth.js `users`도 함께 생김)
2. 로그아웃 후 재로그인 → **가입 폼이 다시 뜨지 않음**
3. "아직 준비 중" 선택 시 `status='preparing'` 저장
