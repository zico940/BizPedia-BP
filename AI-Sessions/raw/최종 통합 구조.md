# 통합 방향

## 최종 통합 구조

# AURA AI Automation Hub

|   |   |
|---|---|
|모듈|설명|
|Policy Agent|안양 청년 정책정보·지원사업 요약|
|Work Agent|업무보고·고객관리 자동화|
|Report Hub|두 모듈의 결과를 리포트로 정리|
|Notification System|마감일, 이슈, 다음 할 일 알림|
|Knowledge DB|저장된 정보를 다시 찾을 수 있는 데이터베이스|

## 통합 방식

처음부터 하나의 앱으로 만들 필요는 없습니다.  
현실적으로는 아래 방식이 가장 좋습니다.

Team A Workflow

       ↓

공통 DB / 대시보드 / 리포트

  

Team B Workflow

       ↓

공통 DB / 대시보드 / 리포트

즉, 두 팀의 자동화는 따로 작동하되, 결과물은 하나의 대시보드나 발표 화면으로 모읍니다.

  

# 통합을 위한 공통 규격

두 팀의 MVP를 10월 이후 하나로 합치려면 9월부터 아래 기준을 맞춰야 합니다.

## 공통 자동화 구조

입력

→ AI 분석

→ JSON 구조화

→ DB 저장

→ 알림 또는 리포트 출력

## 공통 JSON 필드

두 팀 모두 최소한 아래 필드를 포함하는 것이 좋습니다.

{

  "module": "",

  "title": "",

  "summary": "",

  "category": "",

  "key_points": [],

  "next_action": [],

  "deadline": "",

  "priority": "",

  "status": "",

  "tags": []

}
